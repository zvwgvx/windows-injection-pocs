# Run records

One file per executed run, named `YYYY-MM-DD-technique-NN.md`, using
[TEMPLATE.md](TEMPLATE.md). A run record is the only accepted evidence that a
technique's status can move from pending to implemented in the repository README.

Supporting captures (screenshots, third-party tool views) live in `assets/` and are
referenced from the record with a relative link; include the file's SHA-256 when it is
part of the recorded evidence.

Do not edit a record after the fact to match a later run; add a new file instead.
